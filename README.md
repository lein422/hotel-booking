# Система керування готелем
## Запуск

1. Встановити Python 3.11 або новішу версію. Проєкт розроблявся та перевірявся на Python 3.14.
2. Відкрити кореневу папку проєкту.
3. Запустити програму:

```bash
python main.py
```

## Структура проєкту

- `model/` – класи гостей, номерів і бронювань.
- `service/` – бізнес-логіка, робота з JSON та XML.
- `controller/` – взаємодія між сервісом та інтерфейсом.
- `view/` – графічний інтерфейс.
- `data/` – файли даних готелю.
- `tools/` – допоміжні скрипти.
- `logs/` – журнал роботи програми.

## Можливості

- Додавання, редагування та видалення номерів, гостей і бронювань.
- Перевірка доступності номерів, показ вільних номерів за типом і датами.
- Пошук гостя за ПІБ або телефоном.
- Пошук, фільтрація та сортування бронювань.
- Перевірка перетинів дат під час імпорту в кількох потоках через ThreadPoolExecutor.
- Імпорт та експорт JSON.
- Формування XML-звіту про завантаженість номерів.
- Виконання файлових операцій у фоновому потоці.

## Тестові дані

Перед запуском переконайтеся, що існує файл `data/hotel.json`. Для створення тестового файлу виконайте:

```bash
python tools/generate_data.py
```
Результат буде збережено у `data/hotel_test.json`.

## Порівняння одно- і багатопотокового режимів

Після створення `data/hotel_test.json` виконайте:

```bash
python tools/benchmark.py
```

Скрипт 5 разів перевіряє перетини дат в одному потоці та в 2, 4 і 8 потоках і виводить середній час Tn, прискорення S = T1 / Tn та ефективність E = S / n.
